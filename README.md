# ReJoy (demo download)

Download page for the ReJoy demo build: https://axkkkz.github.io/rejoy-app/

ReJoy is a Thai mental-wellbeing app: daily mood check-in on a floating island, small self-care quests, a chat companion with on-device crisis detection, and an SOS page (1323 hotline, offline hospital list) on every screen.

This repository only holds the download page and release APKs. It is a demo for study and portfolio use, not a medical device. If you are in crisis in Thailand, call 1323 (mental health hotline, 24 hours) or 1669 (emergency).
